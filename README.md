# Agnes Aggregator

Local-first, OpenAI-compatible API aggregator for Agnes AI with intelligent multi-key rotation.

**Status:** Early development (Phase -0.5: scaffolding only).

## What it does
- Accepts multiple Agnes API keys.
- Exposes a single OpenAI-compatible endpoint.
- Rotates keys to avoid rate limits.
- Fails over automatically on 429/5xx.
- Ships with a lightweight local web panel.
